# UniVerify V2.0 🎓⛓️
**Decentralized Academic Credential Verification Portal**

## 📌 Overview
UniVerify V2.0 is a Web3 application designed to eliminate academic forgery. It allows institutions to anchor degree metadata to the Ethereum Sepolia Testnet using cryptographic hashes.

## 🚀 Key Features
- **Immutable Ledger:** Records are permanent and cannot be altered once mined.
- **$O(1)$ Search Complexity:** Uses Solidity mappings for instant data retrieval.
- **MetaMask Integration:** Secure administrative signing for certificate issuance.

## 🛠️ Tech Stack
- **Smart Contracts:** Solidity
- **Frontend:** HTML, CSS, JavaScript
- **Web3 Bridge:** Ethers.js
- **Network:** Ethereum Sepolia Testnet
